# APEX GRAND PRIX

An original open-wheel racing game that runs in the browser. Teams, drivers and circuits are fictional.

**Play:** https://thetechdude124.github.io/apex-gp/

Keyboard: W/S or arrows to accelerate and brake, A/D to steer, Space for DRS, Shift for ERS, P to pit, C camera, H for the how-to-play guide. A gamepad works too.

Built with three.js (MIT, see vendor/three/LICENSE).
